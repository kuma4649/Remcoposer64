# Remcoposer64
レム子ポーザー64
レコンポーザー風のシンプルシーケンサーTBD

[概要]
　このツールは、レコンポーザー風のシンプルシーケンサーになるかもしれません。

[機能、特徴]
  数値エディタがメインです。

[必要な環境]  
  ・Windows7(x64)以降のOSがインストールされたPC。私はWindows11Home(x64)を使用しています。  
  ・.NET10をインストールしている必要あり。
